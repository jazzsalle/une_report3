6. 업무흐름도 작성 원칙

① 문서는 상세하게개발·UIUX·기관협의 기준이므로 문서조회, 조치조회, SOP생성의 분리된 단계와 데이터 생성지점을 표시한다.
② 실제 화면은 단순하게문서 선택 화면은 파일명만 표시하고, 조치 선택 화면도 체크 위주로 구성한다.
③ UI 구현과 AI 역할 분리T3Q는 문서와 조치별 상세정보까지 제공하고, 조치 간 관계·분기·필수성은 요구하지 않는다. UNE가 선택 순서 기반 기본 Flow와 실행·이력을 담당.
④ 실제재난/훈련 공통 Core안전한국훈련은 별도 시스템이 아니라 시작 Context와 상황부여 방식만 달리하고, SOP 생성·실행·상황일지·결과보고 Core는 공통으로 사용한다.
v1.0 · T3Q는 조치 상세까지만 제공하고, UNE는 기본 순차 Flow를 구성하며 상황판단 노드·분기조건·분기별 연결대상은 사용자가 편집하도록 역할을 확정. SOP 노드 설정의 근거문서 표시는 제외.
