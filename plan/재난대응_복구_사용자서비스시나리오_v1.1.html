사용자 서비스 시나리오 v1.1 — 개발 반영본

기존 UNE SOP 자동생성 모듈을 재사용하고 실제재난과 안전한국훈련을 하나의 공통 Core 로 처리하는 사용자 서비스 시나리오입니다. v1.1 은 프로토타입(재난상황일지 생성도구, https://une-report3.vercel.app) 개발 결과를 반영해 각 단계의 실제 동작·화면·구현 상태를 기록하고, 개발 중 추가된 SOP 라이브러리 · 조직·연락처(재대본 편성) · 전송그룹 · 상황전파 모바일 응답 · 세부행동 체크 · 시연모드를 시나리오에 추가했습니다.

2. 업무유형별 시작 시나리오

SC-ADM-01 · 사전 준비 (상황 없이 미리) 구현

  • SOP 라이브러리: 재난유형별 SOP 를 미리 작성(매뉴얼 조치로 구성 / AI 생성 / 빈 캔버스) → 초안 편집 → 게시하면 실행 가능 버전. 기본 3종 Seed(호우 초기대응·태풍 주민 사전대피·산불 초동조치)
  • 조직·연락처: 재대본 편성(지휘부 · 13개 협업기능별 실무반 · 유관기관) → 실무반·기관 → 부서 → 사람(직위·전화·이메일). 엑셀 양식 다운로드 → 일괄 업로드(미리보기·검증·추가/병합/교체)
  • 전송그룹: 자주 함께 전파하는 대상(재대본 지휘부, 13개 협업기능반 반장, 유관기관 상황실 등)을 주소록 그룹으로 등록

SC-ACT-01 · 실제재난 구현

  • 지자체·재난유형(풍수해 호우/태풍/대설·산불)·기준시각·발생/영향지역(시군구·읍면동 복수) 입력
  • 기상특보(Seed) 열람 + 기상요약(T3Q Mock, 「확인 필요」 표시)
  • 현재상황은 문서/SOP 추천·AI Context 로 필요 시 입력

SC-TRN-01 · 안전한국훈련 구현

  • 훈련명·목적·시나리오·참여기관·일정 등 훈련 Context 설정
  • 훈련 중 상황부여를 시간순 등록 → 이벤트 원장에 누적
  • 상황부여 → 문서/SOP 추천 → 임무 전파(모바일 링크) → 담당자 수신/확인/완료 → 훈련 상황일지·결과보고

SMS·메일 실발송은 UNE SMS 모듈·메일 서버 연계 자리(모의). 문안 = 제목 + 앞 60자 + 링크(URL 단축 병행 권장).

S10-2
현장 요원 응답 → 상황실 자동 반영
현장 요원은 휴대폰에서 링크(QR)를 열어 상황·조치·내용·수신자만 담긴 단순 화면에서 ① 수신확인 → ② 임무완료 → ③ 조치사항(선택)을 누른다. 인증은 없다. 상황실 화면에는 조치 카드 「상황전파 응답 현황」(수신 n/총·완료 n/총·수신자별 시각·조치사항)과 타임라인·상황일지에 시각과 함께 자동 기록된다.

4. v1.1 반영 사항 (개발 결과)

편집과 실행의 분리 — SOP 라이브러리

  • 상황이 없어도 SOP 작성·게시(버전)·복제·JSON 공유
  • 상황 발생 시 게시본을 배포(스냅샷)해 즉시 실행, 이후 라이브러리 수정은 진행 중 상황에 영향 없음
  • 상황에서 편집한 SOP 를 라이브러리 초안으로 저장·반영

조직·연락처 — 매뉴얼 재대본 편성 기준

  • 지휘부(본부장·차장·총괄조정관·통제관·담당관) · 13개 협업기능별 실무반(담당부서) · 유관기관 → 부서 → 사람
  • 주관/지원/협업은 조치별 역할 → SOP 노드에 기록, 상황전파 시 「조치 담당 추천」
  • 엑셀 양식(구분·실무반/기관·부서명·직위·이름·전화번호·이메일·비고) 일괄 업로드 · 전송그룹

상황전파 → 현장 응답 폐루프

  • SOP 노드 채널(SMS·이메일) → 발송 모달(사람/그룹/추천·미리보기) → 수신자별 링크·QR·문안
  • 인증 없는 모바일 페이지: 수신확인 → 임무완료 → 조치사항(선택), 반응형·큰 버튼
  • 응답은 조치 카드 응답 현황·타임라인·원장·missionAck·결과보고 붙임에 자동 반영(Upstash 저장소)

실행 UX · AI · 출력

  • 세부행동 체크(시각 기록) → 조치결과 자동 정리 · 시작/종료/중지 안내창 · 용어 도움말 · 속성 패널 접기/폭 조절
  • AI 는 사내 UNI RAG(SOP /chat/json · 초안 일반 챗) + 장애 시 대체 생성(circuit breaker)
  • 상황일지·결과보고 Markdown 편집, HWPX 행정문서 양식·DOCX·PDF 내보내기 · 시연모드

  • 관련 문서 파일명 목록 제공
  • 선택 문서 기반 조치목록+조치 상세정보 일괄 제공
  • 기상요약

  • 실 API 규격 확정 시 lib/t3q/adapter 교체

  • 인증·모델 선택은 서버 환경변수·/models 조회로 처리(코드 고정 금지)

UNE

  • 기존 SOP 자동생성 모듈 계약 재사용 · Adapter · 순차 Flow 구성 · 편집기 · 실행 엔진
  • SOP 라이브러리 · 조직·연락처 · 전송그룹 · 상황전파 발송/모바일 응답/반영
  • 원장·상황일지·결과보고 조립·Markdown 편집·HWPX/DOCX/PDF
  • 디자인시스템 적용 · 시연모드 · Vercel 배포(DB 없음) · SMS/KRMS 실연계 자리

6. Seed 검증

1차 · 부산 풍수해 구현·검증

113개 조치 카드 Seed. 문서 조회 → 조치 수신 → 8개 조치 선택 → 기본 SOP 구성·확정 → 실행(4개 조치 결과·SMS·자원) → 상황일지·결과보고(HWPX) 까지 「부산 풍수해 Seed 불러오기」 한 번으로 재현. 조직·연락처 Seed(40명·5그룹)도 부산 매뉴얼 재대본 편성 기준.

2차 · 안전한국훈련 구현

태풍 도상훈련 Seed: 훈련 개요·상황부여 3회 → 문서·조치 → SOP → 임무 수신/확인/완료(버튼 + 모바일 응답 공용) → 훈련 상황일지·훈련결과 보고 목차.

3차 · 경북 산불 시연 시나리오 구현

환경부 산불 실무매뉴얼 10개 조치 Seed와 「산불 초동조치 SOP」 라이브러리. 시연모드 15단계가 상황 등록부터 결과보고까지 산불 상황으로 자동 진행하며, 상황전파 발송·현장 응답 모의 수신을 포함한다. 풍수해와 다른 조직·자원(진화헬기·진화대)에서도 공통 Core 가 동작함을 확인.
