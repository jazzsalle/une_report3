사용자 서비스 시나리오 v1.0

기존 UNE SOP 자동생성 모듈을 재사용하고, 실제재난과 안전한국훈련을 동일한 공통 Core로 처리하는 사용자 서비스 시나리오입니다. 실제재난은 재난상황에서, 안전한국훈련은 훈련계획·시나리오와 상황부여에서 시작하며 이후 문서선택·SOP 생성·실행·상황일지·결과보고 흐름은 공통으로 사용합니다.

대표 1: 실제재난대표 2: 안전한국훈련부산 풍수해 1차 Seed경북 산불 교차검증문서 선택 → 조치 전체 상세 수신 → 선택/정렬 → UNE SOP 구성

2. 업무유형별 시작 시나리오

SC-ACT-01 · 실제재난

  • 지자체·재난유형·기준시각·발생/영향지역 입력
  • 공식 기상특보 열람 + T3Q 기상 MCP 요약
  • 현재상황은 문서/SOP 추천 Context로 필요 시 입력

SC-TRN-01 · 안전한국훈련

  • 훈련계획/훈련시나리오 선택 또는 입력
  • 훈련 대상지역·재난유형·참여기관 등 Context 설정
  • 훈련 중 상황부여를 시간순 등록하고 이벤트 원장에 누적
  • 상황부여 → 문서/SOP 추천 → 임무 전파 → 담당자 확인/완료 → 훈련 상황일지·결과보고로 연결

3. 공통 상세 사용자 서비스 시나리오

단계
사용자 행동
UNE 동작
T3Q/외부 연계
저장·결과
S01
업무유형 선택 및 시작
사용자는 실제재난 또는 안전한국훈련을 선택한다. 실제재난은 지자체·재난유형·기준시각·발생/영향지역을 입력하고 안전한국훈련은 훈련계획/시나리오와 대상지역·재난유형을 설정한다.
UNE mode(실제/훈련)가 포함된 업무 세션과 situation_id를 생성한다.
실제재난 Context 또는 훈련계획·시나리오 Context를 이후 T3Q 문서/SOP 조회에 사용한다.
기록 mode·상황/훈련 기본정보·지역·작성자·생성시각
S02
초기 Context 확인
실제재난은 공식 기상특보와 현재 기상요약을 확인한다. 안전한국훈련은 훈련계획·시나리오와 최초 상황부여를 확인한다.
UNE 실제재난에서는 기상특보 API 결과를 열람용으로 표시하고, 안전한국훈련에서는 상황부여를 시간순 이벤트로 등록한다.
T3Q 실제재난에서는 기상 MCP 요약을 제공하고, 안전한국훈련에서는 훈련자료·위기관리 매뉴얼 RAG를 문서/SOP 추천에 활용한다.
실제: 특보·기상요약 / 훈련: 훈련계획·시나리오·상황부여
S03
관련 문서 조회
관련 문서 조회를 눌러 이번 상황에 적용할 수 있는 문서를 확인한다.
UNE 상황 Context를 T3Q 문서조회 API 요청 규격으로 조립한다.
T3Q 관련 매뉴얼·지침·복구문서를 검색하고 파일명 목록만 반환한다.
추천 문서 파일명 목록
S04
문서 선택
사용자는 파일명 목록에서 필요한 문서를 체크하고 선택 문서로 SOP 추천정보 일괄 조회를 누른다.
UNE 선택된 파일명 목록을 저장하고 다음 조치조회 요청에 사용한다.
문서 선택 화면에는 파일명만 단순 표시한다. 관련도·설명은 기본 화면에 표시하지 않는다.
선택 문서 목록
S05
SOP 추천정보 일괄 조회
선택 문서를 기준으로 T3Q가 반환한 대응조치 목록과 각 조치의 상세정보를 확인한다.
UNE 선택 문서 + 상황 Context로 T3Q SOP 추천 API를 1회 호출하고 응답 전체를 임시 저장한다.
T3Q 조치코드·조치명·단계·담당·지원·협업기관·세부행동·전파대상·필요자원·근거를 포함한 조치 목록과 상세정보를 한 번에 반환한다.
추천 조치 목록·조치별 상세정보·근거
S06
조치 선택·순서조정
사용자는 필요한 조치만 체크하고 선택한 조치로 SOP 구성을 누른다.
UNE T3Q에 다시 요청하지 않고 이미 저장한 응답에서 선택된 조치와 상세정보를 추출한다.
T3Q 조치 선택 이후에는 추가 T3Q 호출을 수행하지 않는다.
선택 조치 목록·사용자 지정 순서
S07
기본 디지털 SOP 구성
생성 과정을 보고 결과 플로우차트를 확인한다.
UNE 기존모듈 이미 수신한 조치 상세정보를 기존 SOP Component 구조로 변환하고, 사용자가 선택·정렬한 순서대로 기본 Process 노드와 순차 연결을 자동 구성한다.
판단노드·분기·연결관계는 T3Q에 요구하지 않으며 필요한 경우 사용자가 기존 SOP 편집기에서 추가·수정한다.
UNE 컴포넌트 모델 / 자동배치 결과
S08
추천 SOP 선택·편집·확정
생성된 SOP에서 노드를 선택/제외하거나 순서·임무·담당·SMS 문안을 편집한 뒤 실행본으로 확정한다.
UNE 추천 원본과 사용자 확정본을 분리 보관하고 실행용 SOP 버전을 저장한다.
근거 문서·페이지·조치코드는 노드 상세에서 확인한다.
SOP 버전·확정 사용자·선택/제외 이력
S09
SOP 실행·모니터링
실행을 시작하고 현재 노드의 임무를 처리한다. 실제재난과 안전한국훈련 모두 좌측 기준 SOP와 우측 실제 수행 타임라인을 비교하며, 훈련에서는 임무 전파·담당자 확인·완료 여부를 함께 기록한다.
UNE 기존모듈 실행/중지, 단계·컴포넌트 진행, 상태·시간·실행자 기록. 판단노드는 실제 분기값에 따라 실행경로를 선택한다.
필요 시 노드별 매뉴얼 근거를 다시 확인한다.
ActionStepHistory / ComponentHistory / 실제 분기경로
S10
조치결과·전파·자원 기록
프로세스 노드에서는 현장메모와 별도로 조치결과를 입력한다. 상황전파 노드는 SMS를 발송하고, 자원 노드는 투입자원을 등록한다.
UNE 조치결과, SMS 발송이력, 자원 투입/회수이력을 노드 실행기록과 연결 저장한다.
SMS 실제 발송 / 향후 KRMS 동일 자원선택 영역 연결 예정.
조치결과·현장메모·SMS·자원 이력·훈련 임무수신/완료 이력
S11
상황 변화 대응 / 복구 SOP 추가
상황 확대 또는 복구 필요 시 관련 문서를 다시 조회하고, 선택 문서의 조치 전체 상세를 다시 받아 필요한 조치를 선택·정렬한 뒤 UNE가 추가 SOP를 구성한다.
UNE 기존 실행이력을 유지한 채 신규/추가 SOP 실행본을 연결한다.
T3Q 변경된 Context로 관련 문서 파일명과 선택 문서의 조치 목록·상세정보를 반환한다.
추가 SOP·변경사유·적용시각
S12
상황일지 자동 누적·생성
사용자는 빈 일지를 처음부터 작성하지 않고 자동 누적된 시간순 기록을 검토·보완한다.
UNE 기존 SOP 실행이력 + 조치결과 + SMS + 자원 + 현장입력 + 기상요약을 상황 이벤트 원장으로 통합하고, 안전한국훈련에서는 상황부여와 임무수신/완료 이력도 함께 누적한다.
T3Q 확인된 기록을 기준으로 상황일지 문안 초안을 생성한다.
이벤트 원장·확인상태·상황일지 초안/수정본
S13
결과보고 구성·출력
사용자는 보고 구분·제목·기준시각을 설정하고, UNE가 제공하는 공통 목차 목록을 불러온 뒤 제목 수정·항목 추가/삭제·순서변경을 수행한다. 이후 시스템 보유자료를 목차별로 선택하고, 피해·복구·인력·장비 등 시스템에서 확보할 수 없는 현황은 제목과 내용을 직접 입력한다.
UNE 공통 목차 목록을 제공하고, 상황 기본정보·기상특보/기상요약·SOP 실행이력·조치결과·SMS 이력·확정 상황일지·훈련 이력 중 사용자가 선택한 자료와 직접입력 현황을 목차별로 조립한다. 미리보기·편집·출력을 제공한다.
T3Q(협의) 보고서 전체 생성의 필수 경로로 사용하지 않는다. 연계규격이 합의된 경우 사용자가 선택한 본문에 대한 문안 요약·정리 기능으로 선택 적용한다.
보고 구분·제목·목차·목차별 반영자료·추가현황·본문·수정이력·HWPX/DOCX/PDF

4. 핵심 변경사항

T3Q 호출 최소화

  • T3Q가 먼저 관련 문서 파일명 목록 제공
  • 사용자 문서 선택 후 조치목록+상세정보를 한 번에 수신
  • 조치 선택 이후에는 T3Q 재호출 없이 UNE 내부에서 SOP 구성

공통 결과보고 구성

  • 공통 목차 목록을 UNE가 제공하고 사용자가 직접 편집
  • 시스템 보유자료만 자동 반영 대상으로 제공
  • 피해·복구·인력·장비 등은 필요한 경우 사용자 직접입력
  • UNE가 본문을 조립하며 T3Q 문안 정리는 협의 시 선택 적용

5. 역할 경계

T3Q

  • 관련 문서 파일명 목록 제공
  • 선택 문서 기반 조치목록+조치 상세정보 일괄 제공
  • 필수/선택·선행/후행·분기조건·다음조치 관계는 제공하지 않음
  • 기상 MCP 요약, 상황일지 문안 초안
  • 결과보고 문안 정리는 연계 협의 시 선택 적용

UNE

  • 기존 SOP 자동생성 모듈 재사용 및 T3Q Adapter 개발
  • 조치 선택·순서조정 UI, Component 변환, 기본 순차 Flow 자동구성
  • 상황판단 노드 추가·분기조건·분기값별 연결대상 사용자 편집 지원
  • SOP 실행·조치결과·SMS·실행이력·상황일지 관리
  • 결과보고 공통 목차·자료선택·사용자 직접입력·본문조립·편집·출력

6. Seed 검증

1차 · 부산 풍수해

문서 파일명 목록 조회 → 조치 상세 수신 → UNE 기본 SOP 구성 → 조치결과 입력 → 공통 목차 편집·자료 선택·추가현황 입력 → 결과보고 조립·출력을 검증한다.

2차 · 안전한국훈련 적용

훈련계획·시나리오·상황부여 → SOP 생성 → 임무 전파/확인/완료 → 시간별 상황일지 → 공통 결과보고 구성·출력을 검증한다.

3차 · 경상북도 산불 및 추가재난

풍수해와 다른 문서·조직·자원을 가진 매뉴얼에서도 T3Q 관계정보 없이 조치 상세만으로 같은 공통 Core와 기본 SOP 구성이 가능한지 교차검증한다.

v1.0 · 결과보고를 재난유형별 전용 양식이나 T3Q 생성에 의존하지 않고, UNE 공통 목차 목록·사용자 편집·시스템 보유자료 선택·추가현황 직접입력·본문 조립 구조로 재정의. T3Q 문안 정리는 협의 후 선택 적용.
